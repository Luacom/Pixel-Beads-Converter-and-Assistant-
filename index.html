尚未生成图纸

大图要分块拼：按拼豆板尺寸切分，拼完一块再拼下一块。点某一块可把光标定位到它没拼完的位置。

怎么用

  1. 导入图片 → 选色卡（新手用 MARD 221）→ 调格数 → 点「生成图纸」。
  2. 点图纸上的任意格子：只是选中并查看它的详细信息（色号、颜色名、HEX、这个色号还剩几颗），不会勾选也不会跳走，可以放心点着看。
  3. 确认手上拿的豆子对了，按底部的 「下一个」：把当前这颗标记为已拼，然后跳到下一个未拼的格子并显示它的信息。
  4. 想不勾选直接往后看，按 「跳过」；想只勾选不移动，按 「只勾选这一颗」。
  5. 习惯「点一下就算拼好」的话，打开工具栏的 「点击即勾选」（或按住 Alt 点格子）。

快捷键

方向键移动选中格（只看信息，不勾选）
Space / Enter=「下一个」：勾选当前这颗并跳到下一个
Tab / Shift+Tab=「跳过」：不勾选，看下一个 / 上一个
Del / Backspace取消当前这颗的勾选（不移动）
Alt+点击临时按「点击即勾选」处理这一下
1…9切换到用量第 N 名的颜色（等于「只看当前色」）
0取消只看当前色
I只看当前色开关
B摆豆模式开关
+ / −放大 / 缩小
Ctrl+Z撤销上一步勾选
Ctrl+S保存项目
Ctrl+V粘贴图片或项目
Ctrl+P打印图纸
F1本帮助

鼠标

  • 左键点格子：选中并显示详细信息（默认）；拖动 = 连续勾选一片
  • 右键点格子：菜单（把这个色号全部标为已拼、换色号等）
  • 滚轮：缩放；按住空格或中键拖动：平移
  • 框选：按住 Ctrl 拖出矩形，可批量勾选/取消

关于色号数据

MARD / COCO / 漫漫 / 盼盼 / 咪小窝 / 优肯 来自社区公开色卡数据（HansBug/pindou-color-data）；Perler / Hama 为社区采样值。屏幕颜色与实际豆子会有差异，重要作品请对实物色卡确认。

本工具纯本地运行，不联网、不上传图片。

只用我有的豆子

粘贴你手上的色号（空格、逗号、换行都能分隔），生成图纸时只会用这些颜色。留空表示不限。

色卡

点任意颜色可以把它设为「只看当前色」，方便按色号检查图纸。
